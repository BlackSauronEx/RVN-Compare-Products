## 2. Обзор продукта

- **Название:** RVN Compare products for woocommerce. **Slug/папка:** `rvn-compare`. **Автор:** Revolen.
- **Идея:** сравнение товаров WooCommerce в стиле DNS / Ситилинк / Regard: список сравнения + отдельная
  страница с удобной таблицей. Часть линейки плагинов бренда RVN (общее меню `RVN` в админке).
- **Одна версия**, без free/pro. Удобная структура файлов. Целевая аудитория: владельцы WooCommerce-магазинов.

### 4.2. Безопасность кода (обязательно всё)

`defined('ABSPATH') || exit;` + `index.php`-заглушки везде; nonce на мутации; capability-проверки;
санитизация входящих (`absint`, `sanitize_text_field`, `sanitize_hex_color`, whitelist для селектов,
валидация CSS-единиц regex); экранирование исходящих (`esc_*`, `wp_kses`-allowlist для SVG);
SVG-санитайзер для иконок из админки; `$wpdb->prepare` при прямом SQL; лимиты длины/количества ID;
черновики/приватные товары гостям не отдавать; HTML в подсказках — запрещён (plain text + `nl2br`).
WooCommerce не активен — гард при активации + понятный `admin_notices`, плагин не падает (R4-06).

### 4.3. Комментарии и язык кода

- Перед **каждой** функцией/методом — короткий комментарий **на русском** в едином стиле PHPDoc:
  назначение, важное поведение, при необходимости `@param`/`@return`.
- Внутренние комментарии — только там, где логика неочевидна.
- Имена классов/методов/переменных/хуков/ключей — **на английском**. Весь UI — переводимый.

### 4.4. Хуки и шаблоны для разработчиков

Фильтры (минимум): `rvn_compare_default_settings`, `rvn_compare_settings_capability`,
`rvn_compare_table_fields`, `rvn_compare_table_products`, `rvn_compare_tabs`,
`rvn_compare_button_html`, `rvn_compare_storage_limit`, `rvn_compare_group_limit`,
`rvn_compare_acf_value`. Экшены: `rvn_compare_added`, `rvn_compare_removed`, `rvn_compare_cleared`.
Шаблоны переопределяемы через `тема/rvn-compare/*.php`. Документация — в `hooks.md`.

Разделение слоёв (R4-09): `includes/` — только PHP-логика и сервисы, `templates/` — только вывод,
`assets/` — только стили и JS (без jQuery на фронте). Рендер таблицы — многошаговый пайплайн:
`entrypoint → context (категории/группы) → product → field-registry → table`; класс таблицы возвращает
структуру данных (контексты, товары, группы, ряды, тулбар), а шаблон только рисует её. Вся логика
сравнения, различий и пустых значений живёт вне шаблона.

### 4.5. SVG allowlist (R3-08, утверждён пользователем 20.09.2026)

Иконки кнопок/тостов, вводимые админом как SVG-код, чистятся `wp_kses` со строгим allowlist.
Основа — `wp_kses` + `ellipse`, `desc`, презентационные stroke-атрибуты.

**Разрешённые теги (11):** `svg`, `g`, `path`, `circle`, `ellipse`, `rect`, `line`, `polyline`,
`polygon`, `title`, `desc`.

**Атрибуты `svg`:** `xmlns`, `width`, `height`, `viewBox`, `fill`, `stroke`, `stroke-width`,
`stroke-linecap`, `stroke-linejoin`, `fill-rule`, `clip-rule`, `opacity`, `class`, `role`,
`aria-hidden`, `focusable`.

**Атрибуты фигур** (`g`, `path`, `circle`, `ellipse`, `rect`, `line`, `polyline`, `polygon`):
`d`, `x`, `y`, `x1`, `y1`, `x2`, `y2`, `cx`, `cy`, `r`, `rx`, `ry`, `width`, `height`, `points`,
`transform`, `fill`, `fill-rule`, `fill-opacity`, `stroke`, `stroke-width`, `stroke-linecap`,
`stroke-linejoin`, `stroke-miterlimit`, `stroke-opacity`, `stroke-dasharray`, `stroke-dashoffset`,
`clip-rule`, `opacity`, `class`.

**`title`/`desc`:** без атрибутов (текст для доступности).

**Запрещено явно:** `script` (JS); `foreignObject` (встроенный HTML+JS); `a`, `use`, `image`
(ссылки/внешние ресурсы, `javascript:`-URL); `animate*`, `set` (лишняя поверхность); атрибут `style`
(CSS с `url()` — эксфильтрация); обработчики `on*`; `href`/`xlink:href`; `id`/`data-*` (иконкам не нужны).

**Правила обработки:**
1. `wp_kses` с allowlist — при сохранении настройки.
2. `wp_kses` с allowlist — при каждом выводе (защита в глубину).
3. Доп. вырезание `javascript:` (регистронезависимо) — страховка.
4. Лимит 10 000 символов на поле иконки.
5. Если при сохранении что-то вырезано — нотис в админке («запрещённые теги/атрибуты удалены»).
6. Не-SVG ввод (emoji/текст) — через `esc_html`, не kses. Встроенные иконки плагина (включая R)
   хранятся в коде и фильтром не обрабатываются.

## 5. Локализация

- Все строки через `__()`/`_e()` и т.д., text-domain `rvn-compare`. Файлы: `.pot` + `ru_RU.po/.mo`
  (английский — исходный язык, отдельный .mo не требуется).
- При активации: дефолтные тексты опций пишутся по `get_locale()` (русский → русские, иначе английские).
- **Паттерн «пустая опция = переведённый дефолт»** (принят по умолчанию): если админ очистил текстовое поле —
  на фронте показывается `__('…', 'rvn-compare')`. В подсказках: «Оставьте пустым для стандартного текста».

## 6. Админка

Меню **`RVN`** (позиция 59 — проверить кодом через `$menu`; если занято — ближайшая свободная рядом;
не дублировать, если уже создано другим плагином линейки — общий хелпер). Иконка — SVG с буквой **R**.
Подпункты: **«Сравнение»** (все настройки) + **«Поддержка»** (общий для линейки; добавлять только если
slug `rvn-support` ещё не зарегистрирован; содержимое: «Будет реализовано в скором времени» / en-аналог).
Доступ: опция (по умолч. `manage_options`) + фильтр. У КАЖДОЙ настройки — пояснение (серый текст/тултип).
Кнопки сброса: на каждой вкладке (своя вкладка) + глобальный сброс всех настроек (с `confirm()`).

### 6.1. Вкладка «Основное»

1. **Страница сравнения:** селект страницы; кнопка «Создать страницу» (проверка пути `rvn-compare` incl. корзина;
   «сбросить страницу» = оставить только шорткод, с `confirm()`); чекбокс «Авто-вставка таблицы»
   (`the_content` + `is_page()` + нет шорткода; в подсказке — не работает с билдерами).
   Метка «— Страница сравнения» в списке страниц (`display_post_states`).
   При активации — автосоздание страницы, если её нет. noindex страницы ✅ (R3-04).
2. **Кнопка на карточке товара:** позиция (по умолч. **после «Купить»**; также перед «Купить», над/под заголовком, 4× overlay, откл.);

## 8. Хранение, синхронизация, лимиты

- **Гости:** `localStorage['rvn_compare']` = массив ID (JSON). Мутации гостей — чистый JS, без AJAX.
- **Залогиненные:** `user_meta 'rvn_compare_list'` (источник правды) + зеркало в localStorage для
  мгновенной кросс-вкладочной синхронизации (событие `storage`, без polling) + `visibilitychange`
  (досинка состояния при возврате фокуса во вкладку, R4-05). Мутации — REST + зеркало.
- **Merge при логине:** JS шлёт гостевой список → union → обрезка (глобальный лимит + групповые, по порядку,
  overflow пропускается) → канонический список → перезапись localStorage.
- **Self-healing:** при чтении — `absint`, `wc_get_product()`, обрезка с конца; несуществующие тихо чистятся.
  Черновики: гостям не показывать; «нет в наличии» — показывать с пометкой.
- **Ленивая очистка:** умершие товары чистятся только при рендере/синхронизации (+хук `deleted_post`),
  без тяжёлых фоновых задач.
- **Настройки:** один option `rvn_compare_settings` (дефолты + merge + санитизация в одном месте);
  отдельной таблицы БД нет. LS-формат клиента — `{items:[…], meta:{…}}`; `user_meta` — источник правды.
- **Лимиты:** глобальный 50 (настр. 1–100); **на категорию/группу 12** (настр. 1–50).
  Правило добавления ✅ (R3-05): товар засчитывается в КАЖДОЙ своей группе (вкл. «Прочее»); если ХОТЯ БЫ
  в одной группе лимит исчерпан — добавление блокируется + тост «максимум» (отдельный настраиваемый текст).
  Превышение глобального лимита 50 — тоже блокировка + тост «максимум» (тот же настраиваемый текст, R4-08).
  Предупреждение в админке, если групповой лимит > глобального.
- REST: `GET table` (HTML вкладки), `POST toggle/remove/clear/merge`, `GET count`. Мутации — nonce.

## 9. Фронтенд: страница сравнения

Подтверждённая скриншотами структура (1.png, 2.png, DNS, Regard) — **БЕЗ липкой колонки слева**:

1. **Тулбар:** вкладки групп/категорий («Смартфоны (3)»); слева под ними — «Только различия»,
   справа — «Очистить». На мобильных — друг под другом. «Добавить товар» — бэклог (R3-01).
2. **Шапка (слайдер):** фото → название (clamp 3 строки, `min-height` = 3 строки) → цена + компактная
   «Купить» в одну строку → ✕ удаление. Внизу таблицы — полноразмерные «Купить» по колонкам.
   Остаток: опция «показывать остаток» (вкл; «В наличии (54)», без учёта остатков — просто «В наличии»).
3. **Группы:** полноширинный заголовок (стиль pill/tab, мягкий фон §6.3).
   **Сворачивание** ✅ (R3-02): стрелка ^ у заголовка (как у DNS); состояние в localStorage;
   опции «разрешить сворачивание групп» (вкл) + «группы по умолчанию» (развёрнуты/свёрнуты).
4. **Поля:** полноширинная строка-название (чёрная, [?] акцентным, неразрывный) + строка значений.
   Пусто → «—». `overflow-wrap: anywhere` + `min-width: 0`. Цена — строкой (отключаемо).
5. **Различия:** нормализованное сравнение; подсветка = фон строки значений (#ffcfcc, настр.);
   «Только различия» — клиентский фильтр; «скрывать пустые» — серверный+клиентский.
6. **Слайдер:** двигаются шапка/строки значений/низ; label-строки и группы статичны. Шаг = 1 колонка,
   `transform: translateX`, кламп индекса, блокировка кликов во время анимации, disabled-состояние стрелок,
   **touch-свайп** (pointer events + snap), ResizeObserver, единый расчёт ширин.
   Ширина колонки = контейнер / N (5/3/2), фиксирована всегда (R2-02).
   Стрелки — по краям шапки, по центру первой строки.
7. **Плавающая панель:** клон шапки (фото/название/цена/купить/✕), `position: fixed`, JS-портал в `body`,
   IntersectionObserver, transform-синхронизация с таблицей, отступ из настроек, на телефоне названия видны.
8. **Тултипы [?]:** у названий полей + у значений атрибутов (описания терминов `pa_*`, тумблер в админке,
   кеширование); десктоп — flip-позиционер свой (~100 строк), z-index выше панели; мобайл — bottom-sheet;
   открытие по hover + клик/фокус (доступность).
9. **Адаптив:** брейкпоинты из настроек → N колонок; тосты — позиция десктоп/мобайл; `prefers-reduced-motion`.
10. **Загрузка:** skeleton → AJAX `GET table` (активная вкладка) → остальные вкладки по AJAX при переключении.
    noindex страницы + share-URL ✅ (R3-04): `wp_robots` + фильтры Yoast/RankMath по возможности.
11. **Шаринг — v1.1** (после релиза): `?rvn-compare=id,…`, соцсети (TG/WA/VK/FB/X/Pinterest/OK/Email/копирование),
    тумблеры сетей + полное отключение.
12. **Пустое состояние:** при пустом списке — аккуратная заглушка (иконка/текст + «перейти в каталог»);
    таблица не рендерится (parts/empty-state.php).

## 17. Критерии готовности Этапа 1 (MVP)

Этап 1 считается готовым, когда ВСЁ нижеследующее проходит на живом стенде
(WP 6.4+/WC 8.0+/PHP 8.1+):

1. Плагин активируется без ошибок; при неактивном WooCommerce — понятный `admin_notices`, не fatal (R4-06).
2. Страница сравнения создаётся (или переиспользуется) с шорткодом `[rvn-compare-table]`, прописывается как
   дефолтная, с меткой `post_states`.
3. Добавление / удаление / очистка — без перезагрузки; тосты (R4-04) показываются корректно.
4. Кнопка «Сравнить»/«Уже в сравнении»: два состояния, toggle (R4-07), обновление всех кнопок и счётчиков.
5. Гости (`localStorage`), залогиненные (`user_meta`), merge при логине и кросс-вкладочная синхронизация
   (`storage` + `visibilitychange`, R4-05) работают.
6. Таблица рендерит по контекстам; вкладки переключаются по AJAX без перезагрузки; «Прочее» и дубли по
   категориям/группам корректны.
7. «Только различия» и подсветка различий работают.
8. Лимиты 50 (глобальный, R4-08) и 12 (на категорию/группу, R3-05) блокируют добавление с тостом «максимум».
9. Простые и вариативные товары: нормализация к родителю (R2-16), CTA «Купить»/«Выбрать вариант».
10. Настройки админки реально влияют на фронтенд (позиция кнопки, акцент, лимиты, дизайн-цвета).
11. Локализация: en-source, `rvn-compare.pot`, `ru_RU.po/.mo`, дефолты по `get_locale()`.
12. Удаление товара с сайта не ломает плагин (self-healing); безопасность по §4.2 соблюдена.
13. Пустое состояние списка отображается корректно (parts/empty-state.php); `visibilitychange` досинкает состояние (R4-05).
