# TESTING.md — журнал реализации и тест-план

Живой документ: заполняется по мере сборки плагина. Каждый блок = шаг
работы → что уже работает → как проверить на стенде → известные ограничения.
Полная приёмка — в ТЗ, §17 «Критерии готовности Этапа 1 (MVP)».

> ⚠️ Файлов `.pot`/`.po`/`.mo` пока нет (локализация по коду развешана, сборка
> переводов — отдельный шаг после стабилизации строк).

---

## Шаг 0 — Скелет и совместимость

**Сделано:**
- `rvn-compare.php` (bootstrap): константы, реестр, автозагрузка классов `RVN_Compare_*`.
- `class-rvn-compare-plugin.php`: singleton-ядро, textdomain.
- `class-rvn-compare-compatibility.php`: Woo-гард + `admin_notices`, декларация HPOS.

**Как тестить:**
1. Установи папку `rvn-compare/` в `wp-content/plugins/`.
2. **Выключи WooCommerce** → активируй плагин → в админке должен появиться
   красный нотис «…требует установленный и активированный WooCommerce», сайт не падает.
3. **Включи WooCommerce** → активируй → нотиса нет, меню «RVN» появилось.
4. Проверь `Настройки WooCommerce → Дополнительно → Функции`:
   RVN Compare отмечен как совместимый с HPOS.

**Ограничения:** нет (шаг завершён).

## Шаг 1 — Хранилище, REST, шорткоды, админка (базовые)

**Сделано:**
- `class-rvn-compare-settings.php`: один option `rvn_compare_settings` (дефолты + merge + санитизация, tab-aware сохранение).
- `class-rvn-compare-storage.php`: `user_meta` источник правды, normalize/self-healing, `add/remove/clear/merge_guest`, лимит 50.
- `class-rvn-compare-rest.php`: `GET /count`, `POST /toggle|/remove|/clear|/merge` (nonce).
- `class-rvn-compare-shortcodes.php`: 5 шорткодов (§7).
- `class-rvn-compare-table.php`: каркас + пустое состояние.
- `class-rvn-compare-admin.php`: меню RVN + «Сравнение»/«Поддержка», 5 вкладок, сбросы.

**Как тестить:**
1. Авторизованным добавь товар кнопкой `[rvn-compare-button]` → счётчик
   `[rvn-compare-counter]` должен стать «1» без перезагрузки.
2. Открой **две вкладки** (магазин и страница сравнения): очисти список на одной,
   переключись на другую → состояние подтянется (событие `storage`, `visibilitychange`).
3. `[rvn-compare-clear]` — спросит подтверждение и очистит.
4. Вкладка «Основное»: поменяй лимит/акцент → Сохранить → значения останутся.
5. Выставь галочки во «Таблице сравнения», сохрани «Основное» → галочки
   НЕ должны сброситься (фикс tab-aware).

**Ограничения:** лимит 12/«Прочее»/группы категорий ещё не применены
(нет Context/Categories); REST `GET /table` возвращает заглушку.

## Шаг 2 — Активатор + страница сравнения

**Сделано:**
- `class-rvn-compare-activator.php`: при активации — дефолты + страница.
- `class-rvn-compare-page-manager.php`: `create_page` / `ensure_page` (без дублей,
  восстановление из корзины) / `reset_page_content` / метка «Страница сравнения»
  в списке страниц / авто-вставка таблицы в конец (опция «Авто-вставка»).
- В админке («Основное»): селект страницы, кнопки «Создать страницу» /
  «Сбросить страницу», ссылка «Посмотреть страницу», уведомления после действий.

**Как тестить:**
1. **Удали плагин** (полностью, с файлами) → **установи заново**.
2. После активации должна появиться страница «Сравнение товаров» со слагом
   `rvn-compare`; в «Страницах» рядом с ней — метка «Страница сравнения».
3. Проверь, что в настройке «Страница сравнения» подставлена эта страница.
4. Открой страницу: должна показываться таблица (каркас/пустое состояние).
5. Удали страницу в корзину → в админке «Создать страницу» → восстановит/назначит.
6. «Сбросить страницу» → в содержимом останется только `[rvn-compare-table]`.
7. Убедись: повторная активация НЕ создаёт дубликат страницы.

**Ограничения:** авто-вставка добавляет шорткод только при включённой опции;
текст названия страницы берётся по локели (`determine_locale()`).

## Шаг 3 — Авто-кнопка сравнения на витрине

**Сделано:**
- `class-rvn-compare-buttons.php`: хуки WooCommerce для карточки (loop) и
  страницы товара (single), 9 позиций из §6.1, фабрика `button_html()`,
  исключения товаров (`excluded_products`).

**Как тестить:**
1. «Основное → Позиция кнопки на карточке» = «После кнопки Купить» → на витрине
   под каждым товаром появилась кнопка «Сравнить».
2. Клик → тост «добавлено», кнопка сменилась на «Уже в сравнении», счётчик ↑.
3. Смени позицию на «Над заголовком»/overlay → кнопка переехала (overlay — best effort).
4. «Позиция кнопки на странице товара» — проверь то же на single product.
5. Позиция «Отключить» → кнопка исчезла с витрины/страницы.
6. Товар-вариация в списке → добавляется родительский товар (normalization).

**Ограничения:** блок «Исключения товаров» в админке ещё НЕ рисуется (значение
`excluded_products` уже читается и фильтрует; UI + сохранение из формы — следующий шаг).
Правило «где показывать» (списки страниц/URL) не реализовано.

## Шаг 4 — Исключения товаров (админка)

**Сделано:**
- `excluded_products` — структурированный: `id => ['archive'=>0/1,'single'=>0/1]`.
- `buttons.php`: контекстная проверка `is_excluded($id,'archive'|'single')`.
- UI «Основное → Исключения товаров»: ввод ID (можно несколько через запятую),
  две галочки контекстов, список с флагами и ✕ удалением, уведомления.

**Как тестить:**
1. Введи ID товара → «Добавить в исключения» → товар в списке.
2. Открой витрину/карточку этого товара → кнопка сравнения исчезла
   (только по отмеченным контекстам).
3. Сними обе галочки → сохрани → товар удалён из исключений.
4. Несколько ID через запятую → добавились все.
5. Пустой/невалидный ID → сообщение об ошибке, без падения.

**Ограничения:** автопоиск товара по названию (`wc-product-search`) пока НЕ подключён —
только ручной ввод ID. (в бэклоге.)

## Шаг 5 — Таблица сравнения (полноценная)

**Сделано:**
- `categories.php`: контексты (группы категорий / отдельные категории / «Прочее»),
  ключи вкладок, дубли товаров по вкладкам.
- `fields.php`: реестр полей — core (цена/артикул/рейтинг/наличие/описания/вес/размеры),
  атрибуты Woo (глобальные + кастомные по тумблеру), ACF/custom-meta (ручной список).
- `table.php`: шаблоны `templates/compare-table.php` + `templates/parts.php`
  (шапка товаров, группы, ряды), пустое состояние, режим `group=`.
- REST `GET /table` теперь рендерит реальную вкладку (AJAX-подгрузка).
- JS `compare.js`: переключение вкладок, «Только различия», сворачивание групп,
  ре-рендер после изменения списка.
- CSS таблицы (колонки/ряды/группы/tab/различия/мобильный вид).

**Как тестить:**
1. Добавь 2–3 товара из разных категорий → на странице сравнения появились вкладки
   («Категория N» с числом), «Прочее» для товаров без категории.
2. Переключение вкладок — без перезагрузки (AJAX).
3. «Только различия» — остаются только расходящиеся строки.
4. Сворачивание/разворачивание групп стрелкой у заголовка.
5. Проверь значения полей (цена/артикул/рейтинг/наличие/вес/размеры) в строках.
6. Шорткод `[rvn-compare-table group="catN"]` — таблица только одной вкладки.

**Ограничения:**
- Слайдер (горизонтальная прокрутка на шаг/стрелки) и плавающая панель ещё НЕ реализованы.
- Серверный only-diff/скрытие пустых строк — включено; клиентский фильтр — есть.
- Вкладка «Таблица сравнения» в админке пока не редактирует группы/поля (UI следующий шаг);
  значения берутся из дефолтов.

## Шаг 6 — Слайдер и плавающая панель

**Сделано:**
- Слайдер: общий scroll-контейнер (шапка + ряды), фиксированная ширина колонки
  «контейнер / N видимых» (R2-02), шаг = 1 колонка, стрелки по краям,
  block/disabling стрелок по краям, синхронизация ширины через ResizeObserver.
- Плавающая панель: компактный клон шапки, появляется при уходе шапки за
  верх экрана, синхронизация прокрутки с основным слайдером, отступ настраивается.
- Sticky-подписи характеристик слева (не уезжают при прокрутке).
- Добавлены настройки: отступ плавающей панели (свои единицы), object-fit фото
  (contain/cover). Вкладка «Основное» разбита на понятные секции.

**Как тестить:**
1. Набери больше товаров, чем видимо на десктопе (напр. 7) → появились стрелки.
2. Клик по стрелке прокручивает ровно на ОДИН товар; на краю стрелка disabled.
3. Ширина колонок = контейнер / 5 (десктоп) и не «расползается» при 2–3 товарах.
4. Подписи характеристик остаются слева при прокрутке (sticky).
5. Прокрути страницу вниз — при уходе шапки появилась плавающая панель сверху;
   её колонки совпадают по горизонтали с основной таблицей.
6. Установи отступ панели 80px → панель видна ниже липкой шапки.
7. На телефоне/планшете число видимых 2/3 работает, touch-свайп прокручивает.

**Ограничения:**
- Плавающая панель — компактная (фото/название/цена/✕, без нижней кнопки «Купить»).
- Touch-свайп использует нативный scroll (без snap на чёткий шаг) — допустимо.
- Синхронизация панели идёт через transform по scrollLeft (стенд-тест обязателен).
